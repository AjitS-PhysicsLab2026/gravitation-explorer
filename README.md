# 🪐 Ajit's Gravitation Studio

Welcome to my very first software application! This is an interactive, modern web-style dashboard specifically designed to calculate and visualize complex gravitational mechanics for competitive exam revision (JEE/NEET).

## 🚀 Core Features
* **Dual Physics Simulation:** Toggle seamlessly between Case 1 (Standard Stationary Object) and Case 2 (Revolving Satellite).
* **High Precision Calculations:** Get instantaneous values for Acceleration due to Gravity ($g$), Gravitational Potential Energy (P.E.), Critical Velocity ($v_c$), and needed Escape Velocity.
* **Flexible Input:** Type altitudes manually (supporting Geostationary orbits up to 36,000 km) or control them using dynamic sliders.
* **Multi-Body Environments:** Test environments for Earth (using standard JEE rounded constants) or the Moon.
* **Interactive Visualization:** Check the optional toggle box to render live Matplotlib curves showing inside/outside planetary behavior.

## 🛠️ Built With
* Python
* Streamlit Framework
* NumPy & Matplotlib
